# 작업자 요약 — SKILL.md 대신 이것만 읽는다 (2026-10-20, 윈도 기계)

SKILL.md 전체를 읽지 않는다. 여기 없는 것이 꼭 필요할 때만 SKILL.md 의 그 장을 grep 으로 찾아 읽는다.
plans/<모듈>.md 도 통째로 읽지 않는다 — 내 묶음 · 화면 이름으로 grep 해서 그 줄과 앞뒤만 본다.

## 우선순위 (토큰을 아낀다)

1. **CRUD + 흐름 숫자**를 원본 · 우리 둘 다 직접 해서 같게 만든다. 이게 바퀴의 본론이다.
   **원본도 우리도 화면에서** 한다(사용자 지시 2026-10-21): 원본을 똑같이 보고 → 원본에서 등록 · 수정 · 삭제 · 검증 → **우리 화면(5180)에서도 같은 자료로 등록 · 수정 · 삭제 · 검증**을
   칸에 넣고 단추를 눌러서 한다. 우리 쪽을 API 로만 확인하고 넘어가지 않는다(API 는 화면으로 한 뒤 숫자를 더 확인할 때만).
   보고의 CRUD 줄에 우리 쪽을 '화면' 으로 했는지 적는다 — 'API 로만' 이면 그 칸은 × 로 치고 이유를 적는다.
2. 조건 · 열 · 버튼 · 문구 · 검증 문구 · 저장 후 안내를 원본 글자 그대로.
3. **디자인 값(줄 높이 · 여백 1px · 색 미세 차이)은 재서 plans 에 적기만 하고 고치지 않는다.** 단, 원본과 꼴이 다른 것(목록 격자 ↔ 출력물 격자, 열 수, 머리 줄 수)은 2번으로 보고 고친다.
   공용 부품(tokens.css · index.css · shell.css · EcListShell · Ec*)은 이번 루프에서 고치지 않는다.
4. 스크린샷은 바퀴에 0~1장. 읽기는 javascript_tool 로 필요한 값만(get_page_text 금지).

## 원본(loginaa) 규칙

- 해도 됨: 등록 · 수정 · 삭제 · 조회 · 상태 바꾸기, 흐름 따라 다른 화면 열기.
- 안 됨: 국세청 전송 · 메일/SMS/팩스/카톡 · 결제/PG · 은행 이체 · 다운로드/파일 생성 · 사용자/권한/보안/회사정보 변경 · Self 환경설정 · [권한요청] · 지울 수 없는 기록을 남기는 동작.
- 결정 대기(누르지 않음): 부가세/원천세 신고서 시험 저장 · 출/퇴근 [출근].
- 내 자료는 `QA<모듈>-` 이름 · 적요 `QA<모듈>`. 바퀴 끝에 원본 · 우리 둘 다 지운다. 남의 QA 자료는 건드리지 않는다.
- 로그인 화면이 보이면 아무것도 누르지 않고 `STATUS: LOGIN_EXPIRED` 로 끝낸다. 429 면 `RATE_LIMITED`.

## 브라우저

- tabs_context_mcp → tabs_create_mcp 로 **내 탭 하나**. 탭 id 를 적어 두고 끝에 반드시 닫는다.
  이카운트 첫 화면 탭(제목 '(주)가장많이쓰는ERP', 주소에 # 없음)은 로그인 유지용 — 쓰지도 닫지도 않는다.
- 이카운트와 우리 앱(5180)을 그 한 탭에서 navigate 로 오간다.
- 입력: form_input(ref + tabId). 누르기: find 로 ref → javascript_tool 로 `.click()`. 키: 대상 요소에 KeyboardEvent dispatch.
  computer 의 클릭 · type · key 는 쓰지 않는다(앞에 떠 있는 남의 탭에 들어간다).
- 저장 전에 폼 값을 읽어 내가 넣은 값만 있는지 본다.
- 우리 앱 탭이 로그인 화면이면(같은 출처 탭들이 토큰을 같이 쓴다) qa 시드 · fixture 의 admin 으로 다시 들어간다. 로그아웃 · 다른 계정 로그인은 하지 않는다.

## 코드 · 검증 · 커밋

- 모듈 경계 · 계층 · Flyway 는 CLAUDE.md 를 따른다(필요한 장만 grep). 다른 모듈 상태는 그 모듈 service 로. 내 모듈 밖 화면은 고치지 않는다(보기만).
- 스키마: `bash qa/next-migration.sh` 로 번호 한 쌍 → 초안은 /tmp/erp-mig-<모듈>/ → 엔티티와 함께 db/migration · db/tenant 둘 다 → 바로 커밋 → 재기동. FK 인덱스 · enum CHECK. `node qa/schema-check.mjs`.
- 무거운 명령(precommit · mvnw · screen-check · shot · mobile-check · style-snapshot)은 잠금 안에서만:
  ```bash
  H=/tmp/erp-heavy.lock; [ -d $H ] && [ -n "$(find $H -maxdepth 0 -mmin +15)" ] && rm -rf $H
  until mkdir $H 2>/dev/null; do sleep 20; done; echo "<모듈> $(date +%T)" > $H/owner
  <명령>; rc=$?; rm -rf $H
  ```
  백엔드 컴파일 확인은 사본에서: `rsync -a --delete --exclude target backend/ /tmp/erp-compile-<모듈>/` (없으면 cp -r) 후 거기서 `MAVEN_OPTS="-Xmx512m -XX:+UseSerialGC" ./mvnw -o -q compile`.
  **MAVEN_OPTS 를 꼭 붙인다** — 상한 없는 컴파일이 1.2GB 를 먹어 공유 서버가 디스크로 밀려나 1분 넘게 멈췄다(2026-10-21 09:52).
- 백엔드 재기동은 커밋한 뒤 `bash qa/restart-backend.sh <모듈> > /tmp/<모듈>-restart.out 2>&1; cat /tmp/<모듈>-restart.out` 로만, 바퀴에 한 번. 파이프로 받지 않는다. exit 2 = 남이 잠금 → 2분 뒤. exit 1 = 바로 고쳐 커밋 후 다시. 갑자기 연결 거부면 남이 재기동 중 → 2분 뒤.
- 프론트 5180 은 직접 껐다 켜지 않는다. 타입체크는 `cd frontend && npm run typecheck`(잠금 안).
- 입력 화면을 고쳤으면 qa/flows/ 에 '입력 → 저장 → 안내 → 따라갈 화면 숫자 → 삭제' 흐름을 더하고 `node qa/shot.mjs` 로 돌린다(잠금 안).
- precommit 실패는 내가 고친 파일 탓만 내 몫. style 기준은 `node qa/style-check.mjs --update <내 .tsx>` 로 내 파일만.
- **임시 인덱스(GIT_INDEX_FILE)로 커밋하지 않는다** — 공유 인덱스에 그 경로의 옛 내용이 남아, 다음 사람이 커밋할 때 내 변경을 되돌린다(2026-10-20 3214c021 이 f9579f3c 에 덮였다). 같은 파일에 남의 미커밋 변경이 있으면: 먼저 `git diff --cached --stat` 이 비었는지 본다(남이 올려 둔 것이 있으면 1분 뒤 다시) → `git add -p <파일>` 로 내 hunk 만 올림 → `git diff --cached` 에 내 줄만 있는지 확인 → `git commit -m …`(경로 없이) → `git diff --cached` 가 다시 비었는지 확인.
- **커밋은 `git commit -- <내 경로들>` 로만**(공유 인덱스에 남이 올려 둔 것이 섞이지 않게). 남의 것을 unstage · reset · checkout 하지 않는다. 커밋 직후 `git show --stat HEAD` 로 내 파일만 들었는지 확인. 메시지 끝에 빈 줄 + `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. 지금 브랜치에 커밋 · 푸시(거절되면 pull --rebase).
- 공용 파일(router.tsx · EcountLayout.tsx · menuPermissions.ts · 마이그레이션)은 고치면 바로 커밋.
- index.lock 오류면 몇 초 뒤 다시(지우지 않는다).

## 기록

- Notion 은 쓰지 않는다. plans/<모듈>.md 의 `## 일치 기록` · `## 남은 것` 표에 **내 줄만** Edit 로 더하거나 고친다(같은 파일을 다른 작업자도 쓴다 — 커밋 직전 git diff 로 남의 줄이 섞이지 않았는지 본다).
- 큰 화면은 정리(plans/<모듈>/<화면코드>.md) → 다시 하기 두 단계로 끊어도 된다.
- 판정: CRUD 양쪽 ○(또는 이유 있는 ×) + 흐름 숫자 같음 + 꼴이 같음 → `대조함·일치`. 3번(디자인 미세 값)만 남았으면 일치로 적고 그 값은 남은 것 표에 '디자인 미세' 로 따로 적는다. 그 밖은 `대조함·남은 것 있음`.
- 화면 5개 또는 60분까지. 끝낼 때 내가 띄운 백그라운드 명령이 남지 않게 한다.
