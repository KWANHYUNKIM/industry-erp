E200072(프로젝트 진행현황 칸반)는 **글 View 본문**이 칸반 판이고, 이 화면은 **게시판 목록 자체**가 칸반 판이다(적용양식 '칸반').
같은 판 부품(열 머리 + 건수 · 카드 = 라벨 칩 + 제목 + [답글 수] + 아랫줄)을 두 화면이 같이 쓸 수 있다.

## 흐름

글 저장(진행상태 X) → 판의 X 열에 카드 + 열 건수 +1. 카드 끌어 놓기 / [진행상태변경] → 옛 열 −1 · 새 열 +1. 선택삭제 → 열 −1.
답글을 달면 카드 제목 뒤 [n]. 라벨변경 → 카드 앞 칩. (원본에서 직접 넣어 보지는 못함 — 위 '못 잼')

## 못 잼

- 원본 저장 · 끌어 옮기기 · 삭제(전달자를 guest 로 못 좁힘)
- 카드 아랫줄이 작성자인지 담당자인지(예시 글은 작성자가 모두 '이카운트' 라 담당자로 보인다)
- [칸반 ▾] 판 · 카드 ⋯ 판 · 열 체크칸 동작

## 우리와 다른 점 (2026-10-14)

1. 화면 · 라우트 · 메뉴가 없다(메뉴 '🔹 이카운트 AI 활용 예시' 다음 자리).
2. PostBoard 에 이 게시판이 없다(KANBAN_SAMPLE — 진행상태 이름 7개, 서버 stage 에 이름을 적는 namedStages 꼴).
3. 칸반 판 부품이 없다. 서버는 이미 있다: stage(진행상태 이름) · labels · PATCH /work-posts/{id}/status(진행상태 바꾸기) · DELETE.
4. 답글이 없다(우리 WorkPost 에 답글 개념 없음) — [n] 은 못 붙인다.
