# Self-Customizing 의 약속

2026-10-13 loginaa 사이트맵 실측(머리 [사이트맵] → `.sitemap` 의 'Self-Customizing' 부분, `li` 깊이로 단을 읽음). SKILL.md 1.0 의 회계1 표와 같은 꼴.

사이트맵 Self-Customizing 실측(위에서 아래, `›` = 한 단 아래):

- 정보관리 › 회사정보변경(회사정보 · 경영요약보고서신청 · 회사로고/도장) · 데이터관리(백업 및 삭제 · 데이터초기화) · API인증키발급
- 사용자관리 › 사용자등록 · 권한그룹 설정 · 권한승인대기현황 · 관리자설정
- 환경설정 › 기능설정 · 기본값설정 · 매핑센터
- 기타관리시스템 › Customer Portal(기본설정 · C-Portal그룹별설정 · 고객ID추가/설정) · Webmail설정(Webmail설정 · Webmail ID 설정) · UserPay설정(UserPay설정 · UserPay그룹별설정)
- 보안관리 › 보안설정 · 사용자접속현황 · 로그인이력감시 · 파일이력조회 · 보안이력현황 · 허용리스트
- 다운로드 › 엑셀자료올리기기능 · 편의기능

**원본에서 해도 되는 것**(SKILL.md 0장 · 다른 작업자 8명이 같은 계정으로 붙어 있다):

- **읽기만** — 열어서 조건 · 열 · 버튼 · 문구 · 칸만 잰다. 저장 · 삭제 · 초기화 · 발급 · 신청 버튼은 누르지 않는다. 우리 쪽은 같은 화면을 만들고 우리 앱에서만 CRUD 해 본다.
- **되돌리기** — 하나를 바꿔 잴 수 있지만 바꾸기 전 값을 먼저 적고, 바꾼 즉시(1분 안에) 원래 값으로 되돌린다. 모든 화면에 영향이 가므로 꼭 필요한 것만.
- **모양만** — 바깥 연동 · 유료 · 다운로드. 누르지 않고 화면 모양만.

우리 쪽에서 사용자 · 권한 · 보안정책을 바꿔 시험했으면 끝나고 원래대로 되돌린다. admin 계정과 로그인 정책은 건드리지 않는다(다른 작업자가 우리 앱에 admin 으로 로그인해 있다).
