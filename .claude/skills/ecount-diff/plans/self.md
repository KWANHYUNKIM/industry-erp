# Self-Customizing 의 약속

2026-10-13 loginaa 사이트맵 실측(머리 [사이트맵] → `.sitemap` 의 'Self-Customizing' 부분, `li` 깊이로 단을 읽음). SKILL.md 1.0 의 회계1 표와 같은 꼴.

사이트맵 Self-Customizing 실측(위에서 아래, `›` = 한 단 아래):

- 정보관리 › 회사정보변경(회사정보 · 경영요약보고서신청 · 회사로고/도장) · 데이터관리(백업 및 삭제 · 데이터초기화) · API인증키발급
- 사용자관리 › 사용자등록 · 권한그룹 설정 · 권한승인대기현황 · 관리자설정
- 환경설정 › 기능설정 · 기본값설정 · 매핑센터
- 기타관리시스템 › Customer Portal(기본설정 · C-Portal그룹별설정 · 고객ID추가/설정) · Webmail설정(Webmail설정 · Webmail ID 설정) · UserPay설정(UserPay설정 · UserPay그룹별설정)
- 보안관리 › 보안설정 · 사용자접속현황 · 로그인이력감시 · 파일이력조회 · 보안이력현황 · 허용리스트
- 다운로드 › 엑셀자료올리기기능 · 편의기능

**원본에서 해도 되는 것**(SKILL.md 0장 · 다른 작업자 8명이 같은 계정으로 붙어 있다):

- **읽기만** — 열어서 조건 · 열 · 버튼 · 문구 · 칸만 잰다. 저장 · 삭제 · 초기화 · 발급 · 신청 버튼은 누르지 않는다. 우리 쪽은 같은 화면을 만들고 우리 앱에서만 CRUD 해 본다.
- **되돌리기** — 하나를 바꿔 잴 수 있지만 바꾸기 전 값을 먼저 적고, 바꾼 즉시(1분 안에) 원래 값으로 되돌린다. 모든 화면에 영향이 가므로 꼭 필요한 것만.
- **모양만** — 바깥 연동 · 유료 · 다운로드. 누르지 않고 화면 모양만.

우리 쪽에서 사용자 · 권한 · 보안정책을 바꿔 시험했으면 끝나고 원래대로 되돌린다. admin 계정과 로그인 정책은 건드리지 않는다(다른 작업자가 우리 앱에 admin 으로 로그인해 있다).

| 차례 | 묶음 | 화면 | 비고 |
|---|---|---|---|
| 1 | 정보관리 | 회사정보변경(회사정보 · 경영요약보고서신청 · 회사로고/도장) · 데이터관리(백업 및 삭제 · 데이터초기화) · API인증키발급 | **읽기만** 전부. 경영요약보고서신청은 메일 발송 신청이라 모양만. 2026-10-13 여섯 화면 모두 **권한 없음**(마스터 계정만) — 남은 것 표 |
| 2 | 사용자관리 | 사용자등록 · 권한그룹 설정 · 권한승인대기현황 · 관리자설정 | **읽기만** 전부(로그인을 흔든다). 2026-10-13 네 화면 모두 **권한 없음** — 남은 것 표. 우리 앱 CRUD 는 QAself- 사용자 · 권한그룹으로만, 끝나면 지운다 |
| 3 | 환경설정 | 기능설정 · 기본값설정 · 매핑센터 | **되돌리기** — 원본 값 하나를 바꿔 재고 1분 안에 되돌린다. 매핑센터(C001122)는 **권한 없음**. 기능설정(C000113) · 기본값설정(C001124)은 열림 — 2026-10-13 읽기만으로 대조(원본 값은 안 바꿈) |
| 4 | 기타관리시스템 | Customer Portal(기본설정 · C-Portal그룹별설정 · 고객ID추가/설정) · Webmail설정(Webmail설정 · Webmail ID 설정) · UserPay설정(UserPay설정 · UserPay그룹별설정) | **모양만** — 바깥 연동 · 유료 |
| 5 | 보안관리 | 보안설정 · 사용자접속현황 · 로그인이력감시 · 파일이력조회 · 보안이력현황 · 허용리스트 | 보안설정 · 허용리스트는 **읽기만**. 현황 · 이력 화면은 조회 조건만 바꿔 본다. 보안설정(C001138)은 열림 |
| 6 (끝) | 다운로드 | 엑셀자료올리기기능 · 편의기능 | **모양만** — 내려받기는 누르지 않는다. **마지막 확인**: 1~5 에서 우리 앱에 바꾼 설정 · 사용자 · 권한이 모두 원래대로인지 |

- 겹침(약속 4): 없음. 인쇄용결재라인등록은 회계1 기초등록 몫(우리 메뉴의 '인쇄서식' 탭은 원본 Self-Customizing 사이트맵에 없다).
