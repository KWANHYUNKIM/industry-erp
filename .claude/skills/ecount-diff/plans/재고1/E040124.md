## 2. 우리

- 특별단가 한 줄 = (판매/구매, 품목, **거래처** 또는 **문자열 단가그룹**, 단가). 그룹 마스터가 없고 그룹 이름이 화면 코드에 박혀 있다(`SALES_GROUPS = ['일반가', '대리점가', '특판가']`, `PURCHASE_GROUPS`).
- 거래처 쪽은 `BusinessPartner.salesPriceGroup / purchasePriceGroup`(문자열)로 그룹을 든다 — 거래처특별단가그룹등록(`/inventory/special-price-group`)이 이 값을 고친다.
- 해석(`SpecialPriceService.resolve`): 단가적용순서설정의 '거래처별특별단가(품목별/품목그룹별)' 중 하나라도 사용이면 → 거래처 지정 단가 → 거래처 그룹 단가. 창고별 · 품목그룹별 조정은 없다.

## 3. 고칠 순서(다시 하기)

1. 스키마(본사 + 테넌트, `bash qa/next-migration.sh`, 초안은 /tmp): `special_price_groups`(code · name · active) · 그룹 ↔ 거래처 / 창고 / 품목그룹 연결 · `special_prices` 를 (group_id, item_id, unit_price, vat_included) 로. 옛 partner · price_group 줄은 옮기거나(그룹 하나씩 지어) 두고 읽기만.
2. 화면 알약 넷 · 열 · 버튼줄 · 품목별 신규 창(위 1장 글자 그대로).
3. 적용단가 탭 = 품목 × 그룹 해석 결과(구분 '품목별단가' · '품목그룹별' …).
4. 거래처특별단가그룹등록(E040120)이 거래처를 그룹에 붙이는 화면이 되도록(그 바퀴에서 원본 재기).
5. **흐름**(앞 작업자 메모 '적용단가 700 으로 저장' 이 이것): 그룹 `QA재고1-특가` 에 품목 · 적용단가 700 → 거래처를 그 그룹에(거래처설정 또는 E040120) → 판매입력(E040205)에서 그 거래처 · 품목 → 단가 700(단가적용순서 '거래처별특별단가(품목별)' 사용일 때), 사용안함으로 바꾸면 출고단가.
   판매입력 품목코드 칸은 JS 입력이 안 먹는다 — `/tmp/erp-chrome-focus.lock` 잡고 `computer` 로(칸 클릭 → 코드 입력 → Enter 는 됐다, 2026-10-14).
