# 인쇄용결재라인등록(회계) — E010106 정리

2026-10-13 loginaa 실측(회계 I › 기초등록 › 인쇄용결재라인등록(회계)). 정리 단계 — 우리 쪽은 아직 안 고쳤다.

## 원본 화면

- 제목 `인쇄용결재라인등록(회계)`. 머리 오른쪽 [도움말] 만(Search · Option 없음).
- 알약 `회계` · `재고` · `관리` — 회계 메뉴로 열면 [회계] 가 켜져 있다. 모듈마다 결재라인이 따로다
  (관리 = E090102 인쇄용결재라인등록(관리) 와 같은 화면의 다른 알약, 재고도 같다).
- 판 둘: `⊙ 결재라인 1` · `⊙ 결재라인 2`(접기 단추). 판마다 격자 하나:

  | (줄 이름) | 명칭 | 가로크기(px) | 글자크기(px) |
  |---|---|---|---|
  | 결재라인 | (비어 있음) | 26 | 12px |
  | 결재자 1 | 담당 | 70 | 11px |
  | 결재자 2 | 대리 | 70 | 11px |
  | 결재자 3 | 과장 | 70 | 11px |
  | 결재자 4 | 차장 | (빈칸 → 저장하면 60) | 11px |
  | 결재자 5 | 상무 | (빈칸 → 60) | 11px |
  | 결재자 6 | 사장 | (빈칸 → 60) | 11px |
  | 결재자 7 | 회장 | (빈칸 → 60) | 11px |
  | 결재자 8 | | | 11px |
  | 결재자 9 | | | 11px |

  결재라인 2 는 처음에 다 비어 있고 글자크기만 결재라인 9px · 결재자 12px.
  `결재라인` 줄 = 결재란 맨 왼쪽 세로 칸(인쇄물에 '결 재' 라고 찍히는 좁은 칸) — 명칭 · 폭 · 글자.
- 칸은 격자 입력(`span.grid-input-data`, 누르면 입력칸). 글자크기는 선택상자(9px · 11px · 12px …).
- 하단 [저장(F8)] · [미리보기] · [H]. 저장하면 안내 없이 그대로(명칭이 있는데 가로가 빈 결재자는 60 으로 채워진다 — 2026-10-13 저장 한 번에 4~7 이 60 이 됐다).
- [미리보기] 창 `결재라인 미리보기`: 결재라인 1 — 좁은 칸 + 담당 · 대리 · 과장 · 차장 · 상무 · 사장 · 회장 일곱 칸(이름 칸 아래 도장 칸). 결재라인 2 — 비어 있어 안 그린다. [닫기].

## 흐름

- 회계 출력물(회계거래조회 › [전표 인쇄] 의 '전표' 창)에 결재라인 1 이 찍힌다 — 2026-10-13 전표 26/10/13-20 인쇄 창의 오른쪽 위 `결재 | 담당 | 대리 | 과장` 칸(이때는 저장 전이라 가로 70 셋만 보였다).
  결재자 4~7 은 가로가 비어 있어 인쇄에 안 나왔고, 저장 뒤에는 60 으로 나올 것 — 다시 하기 단계에서 전표 인쇄로 확인할 것(못 잼).

## 우리 쪽(지금)

- `/settings/print-sign` `PrintSignLinePage.tsx` '인쇄용 결재라인' — 서식 목록(서식명 · 결재란 미리보기 · 기본 · 사용 · 비고 · 처리) + 등록 창(칸마다 직함 · 결재자 이름).
  백엔드 `groupware/printsign`(PrintSignLine · PrintSignSlot: title · signerName · slotOrder, defaultLine).
- 출력은 `utils/print.ts` · `printDocument.ts` 가 **기본 결재란** 하나를 모든 모듈 출력물에 찍는다.

## 다른 점

1. 원본은 모듈(회계 · 재고 · 관리)마다 결재라인 1 · 2 고정 두 벌, 우리는 서식 여러 개 + 기본 하나(모듈 구분 없음).
2. 원본 칸 = 명칭 · 가로크기(px) · 글자크기(px). 우리 = 직함 · 결재자 이름(폭 · 글자 없음).
3. 원본 맨 왼쪽 `결재라인` 줄(폭 26 · 12px), 우리 없음.
4. 원본은 결재자 9칸까지, 이름 있는 칸만 그린다.
5. 원본 화면은 목록이 아니라 한 장짜리 설정 화면 — [저장(F8)] · [미리보기].
6. 메뉴: 우리 회계 I › 기초등록 에 이 화면 메뉴가 없다(관리 쪽 `인쇄용결재라인등록(관리)` → /settings/print-sign 만).

## 고칠 차례(다시 하기)

1. 백엔드: `print_sign_lines` 에 `module`(ACCOUNTING · INVENTORY · MANAGEMENT) · `line_no`(1 · 2) · 결재라인 줄의 폭 · 글자, 칸에 `width_px` · `font_px` (V… 본사 + tenant 둘 다, `bash qa/next-migration.sh`).
   모듈 × 줄 번호 유일. 옛 서식 → 회계 결재라인 1 로 옮기는 백필.
2. 화면: 알약 회계 · 재고 · 관리 + 판 둘 + 격자(명칭 · 가로 · 글자) + [저장(F8)] · [미리보기] — 회계 메뉴로 열면 [회계] 알약. 관리 작업자(E090102)와 같은 화면이므로 알약만 기본값을 다르게.
3. 저장: 명칭 있고 가로 빈 칸 → 60.
4. 출력: 출력물이 자기 모듈의 결재라인 1 을 찍게(`print.ts`), 폭 · 글자 반영. 전표 인쇄로 원본과 견준다.
5. 메뉴 회계 I › 기초등록 에 `인쇄용결재라인등록(회계)`.

원본 자료: 결재자 8 에 QA회계1 을 넣어 보려 했으나 격자 입력이 form_input 으로 안 들어가 저장되지 않았다(남긴 QA 자료 없음). 저장 한 번으로 결재자 4~7 가로가 빈칸 → 60 이 됐다(원본 규칙대로 채워진 것이라 되돌리지 않음).
