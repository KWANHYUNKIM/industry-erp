## 3. 우리와 다른 점 (8)

1. **회계거래조회 적요** — 원본은 적요를 비우면 빈칸, 우리는 `fillVatSlip` 이 거래처명으로 채운다(`desc = … : partner.getName()` → `e.setDescription`). 줄 적요는 원본 전표 인쇄가 거래처명을 찍으니 줄은 그대로 두고 **전표 description 만 빈칸**이어야 한다.
2. **매입/매출장 일자-No.** — 원본은 그날 부가세 전표 일련(-1 · -2), 우리는 `dateNo(r.date, r.no)` 로 회계 docNo(-12 · -13).

4. **매입/매출장 매입/매출 판** — 원본은 한 표 9열(매입공급가액 · 매입부가세 · 매출공급가액 · 매출부가세, 계 · 누계 건수는 합친 수), 우리는 매출표 · 매입표를 따로 둘(VatBookPage 주석에도 '못 쟀다'로 남아 있음 — 이번에 잼).
5. **빈 저장 검증** — 원본은 알림 없이 거래처 칸 빨간 테두리 + 말풍선, 우리는 판 위 `ec-alert` 글줄 `거래처: 자료를 입력 바랍니다.`. 말풍선 글자는 못 잼.
