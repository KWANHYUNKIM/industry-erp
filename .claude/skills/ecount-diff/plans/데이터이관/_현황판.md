## 넘길 일(코더 대기열)

- 재고조정진행단계 [담당자] 열이 실사에서 고른 담당자가 아니라 로그인 계정(ecadmin)을 보여준다 — 원본은 박태선. 실사 전표(slip)에는 employeeId 가 저장되지만 `/api/staged-adjustments` 줄에 없다(백엔드 DTO + StagedProgressPage.tsx:94).
- 재고조정진행단계 [실사] · [조정] 알약이 눌리지 않는다(span) — 원본: [실사] → 메뉴 '조회 · 현황', [조정] → 메뉴 '조정' → 확인 창 → 그 실사 전표만 조정전표 생성(루프 17). `StagedProgressPage.tsx`.
- 출하지시서입력을 주문서입력(f4da517d)처럼 큰 화면 + 메뉴 '출하지시서입력'으로 — 원본 툴바 · 줄 품목코드 칸에 코드 · 거래처/창고 코드칸(루프 18).
- 원본 사용자 정의 칸('새로운 항목 추가' · 기본값) — 입력화면설정 기능(큰 일, 사용자와 범위 정할 것).
- 품목 시리얼/로트 관리 4가지(기본설정 · 필수 · 선택 · 사용안함) — 우리는 lot_managed 하나.
