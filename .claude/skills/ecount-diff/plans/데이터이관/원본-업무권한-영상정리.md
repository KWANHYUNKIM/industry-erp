# 필요한 메뉴에 권한이 없는 경우, 사용자가 직접 권한을 요청할 수 있나요?

- **메뉴 경로**: 영상에서 특정 모듈·메뉴를 지정하지 않음 (판매전표 입력 화면 예시 언급)
- **영상**: https://www.youtube.com/watch?v=ZpsIDIX5-Sc · 1:04 · 업로드 2023-08-07
- **한 줄 요약**: 권한이 없는 메뉴에서 사용자가 직접 마스터(관리자)에게 권한을 요청하고, 마스터가 승인해 권한을 부여하는 절차를 설명합니다.

## 언제 쓰나
업무 중 판매전표 등 필요한 메뉴를 열었을 때 권한이 없어 입력할 수 없는 경우에 사용합니다.

## 사전 설정·전제
- 마스터 아이디로 로그인하는 관리자가 있어야 요청을 승인할 수 있습니다.

## 프로세스
1. 권한이 없는 **메뉴**로 이동합니다.
2. **[권한요청하기]** 버튼을 클릭합니다.
3. 필요하면 **사유**를 입력합니다.
4. 하단의 **[확인]** 버튼을 눌러 요청을 보냅니다.
5. 마스터가 마스터 아이디로 로그인하면 화면 우측 하단에 권한 요청 **알림**이 표시됩니다.
6. 마스터가 알림을 클릭한 뒤 메신저에서 **[보기]** 버튼을 눌러 요청 사유와 내역을 확인합니다.
7. 마스터가 **[승인]** 버튼을 클릭하여 개별권한 또는 그룹권한 변경을 통해 권한을 부여합니다.

## 화면 구성 (조건·항목·버튼)
- **[권한요청하기]** 버튼
- **사유** 입력란 (선택)
- **[확인]** 버튼
- **[승인]** 버튼 (마스터 측 승인여부 항목)

## 결과·연결되는 곳
- 승인되면 해당 사용자에게 개별권한 또는 그룹권한이 부여됩니다.
- 영상에서 구체적인 반영 메뉴는 언급되지 않았습니다.

## 주의·팁
- 자동생성 자막 기준이며, 영상 설명과 댓글이 없어 세부 화면 명칭은 확인되지 않습니다.
- 사유는 필수가 아니지만, 영상에서는 필요하면 기입하라고 안내합니다.

# [이카운트 메뉴별] Self-Customizing - 사용자 추가/수정 - 권한승인대기현황

- **메뉴 경로**: Self-Customizing > 사용자 추가/수정 > 권한승인대기현황
- **영상**: https://www.youtube.com/watch?v=TcI1XUYbuXE · 2:16 · 업로드 2022-04-26

## 언제 쓰나
- 일반 사용자가 권한이 없는 메뉴에 접근하려고 할 때, 마스터에게 권한을 요청하고 처리 결과를 받아야 할 때.

- 권한을 요청하는 사용자는 해당 메뉴 권한이 없는 상태여야 합니다.

3. 마스터가 메뉴에서 **권한승인대기현황**을 엽니다.
4. 요청 내역을 확인한 뒤 처리 방식을 선택합니다.
   - **승인**: 승인 항목에 마우스를 올리면 다음 중 하나를 고를 수 있습니다.
     - 사용자 개별 권한 설정
     - 사용자가 속한 권한 그룹 자체의 권한 설정
   - **반려**: 요청을 반려합니다.
5. (개별 설정 선택 시) 권한 설정 창에서 해당 메뉴의 **모든 권한**을 부여하도록 선택합니다.

6. 설정을 **저장**합니다.
   - 요청자의 ERP 화면을 새로고침하면 해당 메뉴 권한이 부여된 것을 확인할 수 있습니다.
   - 요청자와 승인자 모두 메신저로 승인 결과 알림을 받습니다.
7. 승인 이력을 확인하려면 화면 상단의 **조회**를 클릭하고, 기준일자나 특정 ID, 승인 여부 등 원하는 조건을 설정합니다.

## 화면 구성 (조건·항목·버튼)
- **조회 조건**: 기준일자, 사용자 ID, 승인 여부
- **버튼**
  - 조회
  - 승인 (마우스 오버 시 개별 권한 / 권한 그룹 설정 선택)
  - 반려
  - 상세 권한 설정
  - 저장
- **상세 권한 항목**: 입력, 수정, 삭제, 외부 전송 등 (영상에서 언급된 항목 기준)

## 결과·연결되는 곳
- 승인하면 요청자의 해당 메뉴 접근 권한이 부여되고, 요청자와 승인자에게 메신저 알림이 갑니다.

########## 0083_[이카운트실전] Self-Customizing - 사용자관리 - 권한설정/
# [이카운트실전] Self-Customizing - 사용자관리 - 권한설정

- **메뉴 경로**: 셀프 커스터마이징 > 사용자 관리 > 권한 그룹 설정 (개별 설정은 사용자 추가/수정 > 권한 탭)
- **영상**: https://www.youtube.com/watch?v=hzJKN4mJBPE · 7:16 · 업로드 2021-05-18
- **한 줄 요약**: 사용자 ID별로 권한을 일일이 지정하지 않고, 권한 그룹을 만들어 메뉴·양식·확인·허용·기타 권한을 그룹 단위로 설정한 뒤 사용자에게 연결하는 기능.

## 언제 쓰나
- 부서별, 업무 파트별, 직급별로 사용할 수 있는 메뉴나 기능이 같은 사용자가 여러 명일 때
- 특정 양식(출력물)을 특정 그룹만 쓰지 못하게 하거나, 전표 확인 절차를 그룹마다 다르게 두고 싶을 때
- 특정 품목·거래처·창고·부서 자료만 입력·조회하도록 제한하고 싶을 때

## 사전 설정·전제
- 사용자 추가/수정 메뉴에 사용자 ID가 등록되어 있어야 합니다.
- 권한 그룹을 쓰려면 먼저 권한 그룹 설정 메뉴에서 그룹을 만들어야 합니다.
- 확인 절차를 쓰려면 확인 권한자를 지정할 수 있어야 합니다(확인 권한자 지정 방법은 자막에서 확인되지 않음).

## 프로세스
1. **사용자 기본 권한 확인(개별 ID)**
   - 사용자 추가/수정 메뉴에서 ID를 클릭합니다.
   - **권한** 탭에서 기본 권한을 **모든 권한** 또는 **권한 없음** 중에서 선택할 수 있습니다.
2. **권한 그룹 생성**
   - 권한 그룹 설정 메뉴 하단의 **신규** 버튼을 클릭해 그룹을 만듭니다.
   - 예: 부서별로 그룹을 만듭니다.
3. **그룹별 메뉴 권한 설정**
   - 그룹을 선택하고 **메뉴 권한 설정** 버튼을 클릭합니다.
   - 상단 탭별로 메뉴가 구분되어 있으며, 각 메뉴를 클릭해 개별로 권한을 정합니다.
     - **권한 없음** 또는 **모든 권한** 중 선택합니다.
     - **모든 권한**을 선택하면 기능 권한을 모든 권한에 맞출지 묻는 알림이 뜨고, **확인**을 누릅니다.
   - 세부 권한이 필요하면 우측의 **상세 권한 설정** 버튼을 누릅니다. 입력, 수정, 삭제, 외부 전송, 인쇄 등을 세부적으로 정합니다.
   - 상세 권한 창에서 **확인**을 누르고, **설정** 버튼으로 모든 권한이 반영되었는지 확인한 뒤 **적용**합니다.
4. **그룹별 양식 권한 설정**
   - 양식 권한 탭에서 각종 양식의 사용 여부를 정합니다.
   - 예: 특정 그룹이 판매 현황 기본 양식을 쓰지 못하게 하려면 해당 양식을 클릭합니다.
   - 좌측 권한 항목에서 **지정 사용자**를 선택하고 **설정**을 누른 뒤 **사용 불가**에 체크합니다.
5. **그룹별 확인 권한 설정**
   - **설정** 버튼을 눌러 확인 권한과 확인 절차 적용 여부를 정합니다.
   - 확인 절차를 거쳐야 한다면 확인 처리를 할 **확인 권한자**를 지정합니다.
   - 확인 절차를 **미적용**으로 설정하면, 해당 그룹 ID가 작성한 전표는 별도 확인 없이 바로 확인 전표로 처리되어 장부에 반영됩니다.
6. **그룹별 허용 권한 설정**
   - **설정** 버튼을 눌러 품목, 거래처, 창고, 부서 등 허용 범위를 정합니다.
   - 모든 권한에 체크되어 있으면 등록된 모든 자료를 입력·조회할 수 있습니다.
   - 특정 자료만 허용하려면 **허용 권한**에서 해당 항목에만 체크한 뒤 우측 **설정** 버튼을 누릅니다.
7. **그룹별 기타 권한 설정**
   - **설정** 버튼을 누르면 권한 적용 범위부터 단가·금액 수정 허용 여부까지 여러 항목을 설정할 수 있습니다.
8. **사용자에게 권한 그룹 연결**
   - 사용자 추가/수정 메뉴에서 해당 ID를 클릭합니다.
   - **권한** 탭에서 기본 권한을 해당 **권한 그룹**으로 선택합니다.
   - 기존 개별 설정 권한은 기본 권한을 바꿔도 유지됩니다. 개별 설정도 기본 권한을 따르게 하려면 하단의 **취소** 버튼을 눌러 적용합니다(자막 기준 표현).
9. **그룹 적용 사용자 확인**
   - 권한 그룹 설정 메뉴에서 그룹별 **사용자 보기** 버튼을 누르면 해당 그룹이 적용된 사용자를 확인할 수 있습니다.

## 결과·연결되는 곳
- **확인 권한 설정**: 확인 절차를 적용하면 전표는 확인 권한자가 확인한 뒤 장부에 반영됩니다. 미적용이면 작성 즉시 확인 전표로 처리되어 장부에 반영됩니다.
- **양식 권한 설정**: 사용 불가로 지정된 그룹은 해당 출력 양식을 사용할 수 없습니다.
- **허용 권한 설정**: 허용된 품목, 거래처, 창고, 부서의 자료만 입력·조회됩니다.
- 메뉴, 양식, 확인, 허용, 기타 권한의 자세한 내용은 영상에서 각각 메뉴 권한, 양식 권한, 확인 권한, 허용 권한, 기타 권한 강좌를 참고하도록 안내합니다.

## 주의·팁
- 개별 사용자 기본 권한을 바꿔도 기존 개별 설정은 자동으로 바뀌지 않습니다. 그룹 기본 권한을 따르게 하려면 별도 적용이 필요합니다.
- 확인 절차를 미적용으로 두면 전표가 확인 없이 바로 장부에 반영됩니다. 이 설정은 검토가 필요 없는 그룹에만 적용하세요.
- 허용 권한에서 모든 권한이 체크되어 있으면 제한이 걸리지 않습니다. 특정 자료만 허용하려면 전체 체크를 해제하고 해당 항목만 체크해야 합니다.
- 그룹을 부서·업무·직급 기준으로 나눠 만들고, 메뉴 권한 등을 먼저 설정한 뒤 사용자에게 연결하는 순서가 권장됩니다(영상의 흐름 기준).

- 권한 그룹을 쓰려면 권한 그룹 설정 메뉴에서 그룹을 먼저 만들어야 합니다.

## 프로세스
1. **사용자 추가·수정** 메뉴에서 대상 아이디를 클릭합니다.
2. **권한** 탭에서 해당 아이디의 **기본 권한**을 확인합니다.
   - 기본 권한은 **모든 권한** 또는 **권한 없음** 중에서 선택합니다.
3. (권한 그룹 사용 시) **권한 그룹 설정** 메뉴에서 하단의 **신규** 버튼으로 그룹을 만듭니다.
   - 예: 팀별로 "영업팀", "구매팀" 등 그룹을 나누어 생성합니다.
4. 생성한 그룹마다 아래 다섯 가지 권한을 설정합니다.
   1. **메뉴 권한**: 메뉴별로 **권한 없음** 또는 **모든 권한**을 선택합니다. 상단의 메뉴 구분(모듈별 탭)에서 메뉴를 골라 설정합니다.
      - **모든 권한**을 누르면 "기능 권한을 모든 권한에 맞추어 변경하겠냐"는 알림이 뜹니다.
      - 기능 권한은 우측 **상세 권한 설정**에서 보이는 입력·수정·삭제 등의 세부 권한입니다.
      - 세부 항목을 바꾸려면 상세 권한을 수정한 뒤 적용합니다.
   2. **양식 권한**: 출력물 양식(기본 양식과 사용자가 추가한 양식)별로 사용 여부를 정합니다.
      - 양식을 클릭한 뒤 좌측 권한 항목에서 **지정 사용자**를 선택하고 **설정**을 누릅니다.
      - 그룹별로 해당 양식의 사용 가능 여부를 고릅니다.
   3. **확인 권한**: 회계·재고 전표를 장부에 반영하기 전 확인(승인) 절차에 대한 권한입니다.
      - 그룹 전체가 확인 권한자라면 **확인 권한**을 선택합니다.
      - 그룹원이 확인 절차를 거쳐야 한다면 메뉴별로 적용 여부를 설정합니다.
      - **미적용**으로 두면 해당 그룹이 작성한 전표는 별도 확인 없이 바로 확인 전표가 되어 장부에 반영됩니다.
   4. **허용 권한**: 특정 품목·거래처·창고·부서·계정 등 자료 범위를 제한합니다.
      - 모든 권한이면 등록된 모든 자료를 입력·조회할 수 있습니다.
      - 특정 자료만 허용하려면 허용 그룹을 선택한 뒤 우측 **설정**을 눌러 범위를 지정합니다.
   5. **기타 권한**: **설정**을 눌러 권한 적용 범위, 단가·금액 수정 허용 여부 등 세부 항목을 정합니다.

- 설정한 권한은 해당 아이디로 로그인했을 때 메뉴 접근과 행위 가능 여부에 바로 반영됩니다.
- 영상 예시: 재고·재고원·영업관리·판매 업무를 **권한 없음**으로 두면 판매 조회, 판매 등 판매 관련 메뉴 클릭 시 접근이 막힙니다.
- 영상 예시: 판매 업무의 예외 행위에서 수정·삭제를 **권한 없음**으로 두면 판매 전표는 신규 입력만 가능하고, 판매 조회에서 수정·삭제를 시도하면 권한 없음 알림이 뜹니다.
- 영상 예시: 판매 업무의 예외 메뉴에서 **판매 일괄 회계 반영**을 **권한 없음**으로 두면 다른 판매 메뉴는 사용 가능하지만 해당 메뉴는 자물쇠 표시와 함께 권한 없음 문구가 나타납니다.

## 주의·팁
- 기본 권한 설정 방식에 따라 나머지 업무의 기본 상태가 달라지므로, 먼저 기본 권한을 정한 뒤 예외를 추가하는 순서가 편합니다.
- 권한 그룹이 **기본 권한**을 따르는 상태에서는 기본 권한 변경이 개별 업무에도 함께 반영됩니다. 특정 업무만 고정하려면 **개별 권한**으로 바꿔야 합니다.
- **업무 권한 없음**은 조회조차 막히므로, 입력·수정·삭제만 제한하고 싶다면 예외 행위를 사용해야 합니다.
- 마스터 아이디는 여기서 설정한 권한의 영향을 받지 않습니다.

# [이카운트실전] Self-Customizing - 사용자관리 - 사용자추가수정 - 기본권한

- **메뉴 경로**: Self-Customizing > 사용자 관리 > 사용자 추가/수정 > 권한 탭 (권한 그룹 설정 메뉴 포함)
- **영상**: https://www.youtube.com/watch?v=seSFeRN20pk · 4:34 · 업로드 2021-05-18
- **한 줄 요약**: 부서·업무 파트별로 같은 권한을 묶은 권한 그룹을 만들고, 사용자의 기본 권한에 연결해 권한 설정을 간편하게 하는 기능이다.

## 언제 쓰나
- 영업팀처럼 같은 부서나 업무 파트 사용자에게 동일한 메뉴 권한을 일괄 부여해야 할 때
- 사용자를 한 명씩 개별 설정하지 않고 그룹 단위로 권한을 관리하고 싶을 때

## 사전 설정·전제
- 사용자 아이디가 사용자 추가/수정 메뉴에 등록되어 있어야 한다.
- 영상에서는 권한 그룹을 먼저 만든 뒤 사용자 아이디의 기본 권한에 연결하는 순서로 설명한다.

## 프로세스
1. **사용자 추가/수정** 메뉴에서 대상 사용자 아이디를 클릭한다.
2. **권한** 탭에서 기본 권한 항목을 확인한다.
   - 기본 권한 선택지는 **기본 메뉴 권한 없음**과 **기본 메뉴 모든 권한** 두 가지다.
   - 사용자 아이디를 처음 만들 때 모든 메뉴 권한을 줄지 말지를 여기서 정한다.
3. 좌측 **권한 그룹 설정** 메뉴에서 하단 **신규** 버튼을 클릭한다.
4. **권한 코드**와 **권한명**을 입력하고 저장한다. (예: 영업팀 사원용이면 "영업팀 권한"으로 등록)
5. 권한 그룹 목록에서 만든 그룹을 선택하고 **메뉴 권한**의 **설정** 버튼을 클릭한다.
   - 메뉴가 탭별로 분류되어 있으며, 탭을 눌러 하위 메뉴별로 권한을 설정한다.
   - 메뉴 권한을 전혀 주지 않으려면 **권한 없음**에 체크한다.
   - 전체 권한을 주려면 **모든 권한**에 체크한다.
6. 특정 메뉴만 권한을 주려면 해당 메뉴의 **모든 권한**을 체크한다.
   - 확인 알림창이 뜨며, 확인을 누르면 상세 권한 값도 함께 설정된다.
7. 특정 메뉴의 세부 권한만 바꾸려면 **상세 권한**의 **설정** 버튼을 눌러 해당 값을 **0**으로 만든다.
   - 상세 권한은 각 메뉴의 입력, 수정, 삭제, 외부 전송 등을 나눠 설정하는 항목이다.
8. **사용자 추가/수정** 메뉴에서 해당 아이디를 클릭하고 **권한** 탭의 **기본 권한** 항목에 권한 그룹을 연결한다.
9. 개별 설정된 권한까지 기본 권한을 따르게 하려면 하단의 **취소** 버튼을 눌러 적용한다.
   - 영상에서는 "취소" 버튼으로 적용한다고 설명하지만, 자막 오인식 가능성이 있어 실제 화면에서 버튼명을 확인해야 한다.

### 권한 그룹과 개별 권한을 함께 쓰는 경우
- 같은 영업팀 권한을 주되 일부 메뉴만 다르게 하려면, 기본 권한은 영업팀 권한으로 두고 **메뉴 권한 설정**에서 해당 메뉴만 **개별 권한**을 체크한 뒤 다른 값을 지정한다.

## 화면 구성 (조건·항목·버튼)

| 위치 | 항목·버튼 | 설명 |
|---|---|---|
| 사용자 추가/수정 > 권한 탭 | 기본 권한 | 기본 메뉴 권한 없음 / 기본 메뉴 모든 권한, 또는 권한 그룹 연결 |
| 사용자 추가/수정 > 권한 탭 | 메뉴 권한 | 사용자별 개별 메뉴 권한 설정 |
| 사용자 추가/수정 > 권한 탭 | 기타 권한 | 체크되어 있으면 권한 그룹의 값을 따름 |
| 권한 그룹 설정 | 신규 | 권한 그룹 생성 |
| 권한 그룹 설정 | 권한 코드, 권한명 | 그룹 식별 정보 |
| 권한 그룹 설정 > 메뉴 권한 | 설정 | 탭별 하위 메뉴 권한 지정 |

## 결과·연결되는 곳
- 권한 그룹을 기본 권한으로 연결하면 해당 사용자에게 그룹의 메뉴 권한과 상세 권한이 적용된다.
- 기타 권한에 체크되어 있으면 권한 그룹에서 설정한 값을 따른다.
- 기본 권한을 바꿔도 이미 개별 설정된 권한은 그대로 유지된다. 기본 권한을 따르게 하려면 별도 적용이 필요하다.

## 주의·팁
- 기본 권한을 바꾼 뒤에도 개별 설정된 메뉴 권한은 변경되지 않는다. 기본 권한을 따르게 하려면 개별 설정을 해제하는 적용 과정이 필요하다.
- 모든 권한을 체크하면 상세 권한도 함께 전부 부여된다. 일부 상세 권한만 막으려면 해당 값을 0으로 바꾼다.
- 부서별·업무 파트별·직급별로 권한 그룹을 나눠 두면 사용자마다 개별 설정하는 번거로움을 줄일 수 있다.
- 각 권한의 세부 설정 방법은 영상에서 안내하는 별도 동영상 강좌에서 확인할 수 있다.

# 새로 등록한 ID에 다른 사용자의 권한을 동일하게 부여하고 싶어요

- **메뉴 경로**: Self-Customizing > 사용자관리 > 사용자추가/수정

## 언제 쓰나
신입사원이나 신규 담당자의 ID를 새로 만들었는데, 이미 권한이 세팅된 기존 사용자와 같은 업무 권한을 주어야 할 때 사용합니다. 권한을 메뉴별로 하나씩 체크하지 않아도 됩니다.

## 사전 설정·전제
- 권한 원본이 될 기존 사용자 ID가 이미 권한을 갖추고 있어야 합니다.
- 권한을 부여할 새 사용자 ID가 먼저 생성되어 있어야 합니다(프로세스 2단계에서 생성하는 경우도 포함).

1. **Self-Customizing > 사용자관리 > 사용자추가/수정** 메뉴로 들어갑니다.
2. **[신규(F2)]** 버튼을 클릭해 새 ID를 생성합니다.
3. 화면 하단의 **[권한복사]** 버튼을 클릭합니다.
4. **원본대상**에 기존 사용자를 불러와 지정합니다.
5. **복사대상**에서 새로 등록한 사원을 클릭해 지정합니다.
   - 복사대상은 한 명이 아니라 여러 ID를 지정할 수 있습니다.
6. **[저장(F8)]** 버튼을 클릭해 설정을 마칩니다.

| 구분 | 항목 | 설명 |
|---|---|---|

| 항목 | 복사대상 | 권한을 받을 새 사원 ID(복수 지정 가능) |
| 버튼 | [신규(F2)] | 새 사용자 ID 생성 |
| 버튼 | [권한복사] | 원본 사용자의 권한을 복사하는 화면 호출 |
| 버튼 | [저장(F8)] | 권한 복사 설정 저장 |

## 결과·연결되는 곳
영상에서 언급 없음. 다만 저장하면 복사대상으로 지정한 새 사용자 ID에 원본 사용자의 권한이 설정되는 것으로 이해할 수 있습니다.

## 주의·팁
- 복사대상에 여러 ID를 함께 지정하면 같은 권한을 여러 사람에게 한 번에 줄 수 있습니다.
- 원본 사용자의 권한이 정확한지 먼저 확인한 뒤 복사하는 것이 안전합니다. 영상은 복사 후 개별 수정 방법을 다루지 않습니다.

- 영상에서는 전표 이력(**H** 버튼)에서 최초 작성자와 최종 수정자를 확인할 수 있다고 설명합니다.

## 주의·팁
- 영상 예시에서 구준호 아이디는 **조회 범위 = 최초 작성 > 작성자**, **수정 범위 = 최종 수정 > 수정자**로 설정했습니다. 그 결과 최초 작성자가 다른 사용자인 전표는 목록에 보이지 않았습니다.
- 최초 작성자가 다른 사용자이고 최종 수정자가 본인이 아닌 전표를 수정하려 하면 "권한이 없습니다" 알림창이 나타납니다.
- 설정 후에는 반드시 마스터 아이디와 해당 아이디에서 같은 조회 화면을 비교해 확인하세요.
- 전표 조회 범위는 권한 그룹으로 일괄 관리하고, 예외 사용자만 **별도 권한**으로 지정하면 관리가 편합니다. (영상 설명을 바탕으로 한 일반적인 운영 팁입니다.)
