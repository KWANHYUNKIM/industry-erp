# 우리(localhost:5180, 회사 0005) — Self-Customizing 클릭 기록 (2026-10-30, 고친 뒤 다시 눌러 봄 · 열고 닫기만)
# 형식: [누른 것] :: 열린 것 (고치기 전: …)

## 틀(기능설정 · 기본값설정 · 보안설정 공통, components/EcSettingSheet)
[입력 후 [Enter] 칸] :: 판 · 묶음 · 줄 이름 중 낱말 든 것을 주황(#f6882d · 흰 글 · 둥글기 6)으로 칠함, Enter 마다 다음 것, 끝에서 처음으로, 접혀 있으면 폄 (고치기 전: 낱말 든 줄만 남기고 나머지를 숨김)
[도움말] :: '{화면} · 도움말' 창 — 알약 · 항목 이름 · 찾기 · 전체접기 쓰는 법 (고치기 전: 단추 없음)
[알약] :: 그 모듈 판 — 같음
[전체접기] :: 다 접힘 → '전체펼치기' — 같음
[▼ 판 · 묶음 이름] :: 그것만 접힘 — 같음
[고정값 줄 이름] :: 원본 창 제목으로 읽기 전용 창(⊙이름 · 원본 설명 · 막힌 칸 · '우리 ERP 에서는 고정값이라 바꿀 수 없습니다.' · [닫기]) (고치기 전: 눌러도 아무 일 없음)
