# 클릭 대조 — 전체 현황 (2026-10-30 시작)

사용자 요청(10-30): 원본의 **모든 단추 · 링크를 눌러** 무엇이 열리고 어디로 가는지까지 우리와 똑같이. 메인부터 처음부터 차례로 다 보고, 여기 기록해 안 된 곳을 찾아 고친다.

## 차례 · 방법
1. 원본에서 그 화면의 클릭 가능한 것을 **전부** 눌러 본다(저장 안 함 · 닫기) → `click-orig-<화면>.txt`
2. 우리 화면도 같은 차례로 눌러 본다 → `click-ours-<화면>.txt`
3. 줄마다 같음 / 다름 / 빠짐 → `대조-<모듈>.md`
4. 코더가 고침 → 커밋 번호를 여기 적는다 → 다시 눌러 확인(재확인)

상태 표시: (빈칸) 아직 · 원본 = 원본 기록함 · 대조 = 다른 점 적음 · 고침 = 코더 커밋 · ✔ = 재확인 끝
