# 그룹웨어 의 약속

2026-10-13 loginaa 사이트맵 실측(머리 [사이트맵] → `.sitemap` 의 '그룹웨어' 부분). SKILL.md 1.0 의 회계1 표와 같은 꼴. 차례 · 끝 판정은 SKILL.md 1.0 · 7장.

그룹웨어의 게시판 메뉴(이모지가 붙은 것 · '(예시)')는 이 회사가 **게시판 설정으로 만든 게시판**이다 — 화면 틀은 같은 게시판 하나이고 입력항목만 다르다.
같은 틀은 한 바퀴로 묶어도 된다(1장 '같은 틀의 출력물 여럿'). 쪽지 · 메일 · 알림 발송, 남의 결재문서 · 쪽지 열기(읽음 표시)는 하지 않는다.
