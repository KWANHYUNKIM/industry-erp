## 5. 막을 규칙 (다시 쌓이지 않게)

현재 도구: `oxlint`(`react/rules-of-hooks` · `only-export-components` 만 켜짐, `frontend/.oxlintrc.json`) + `qa/style-check.mjs`(인라인 · 색 · 팔레트 래칫) + `qa/arch-check.mjs`(백엔드 모듈 간선). **프론트 import 규칙 도구는 없다.**

1. **`qa/front-arch-check.mjs`(신설, `arch-check` 와 같은 래칫 방식):** import 를 재서
   - `pages/A` → `pages/B`(모듈이 다른 것) 금지 — 지금 3 건을 KNOWN 으로 박고 줄면 기준을 조인다.
   - `components` → `features`, `utils` → `components`/`features` 금지 — 지금 5 + 3 건 KNOWN.
   - `features/A` → `features/B` 금지(단 `features/auth` · `features/preference` 는 허용 목록 — 사실상 공용이므로 장기적으로 `components/` 나 `app/` 로 승격).
   - 추가: `pages/` 안 비페이지 부품(`*Modal.tsx` 등)이 다른 페이지에서 쓰이면 경고.
   `precommit.sh` 에 한 줄 추가. oxlint 에는 `import/no-restricted-paths` 같은 규칙이 없으므로(oxlint 는 아직 지원이 제한적) 자체 스크립트가 낫다.
2. **같은 이름 지역 함수 래칫 `qa/dup-check.mjs`:** 파일 최상위의 `const won|num|fmt|today|ymd|pad|pad2|monthStart|monthEnd = …` 를 세어 `qa/dup-baseline.json` 에 파일별로 적고 **늘면 실패**(새 파일 기준 0). 정식 `utils/format.ts`·`periods.ts` 만 허용. 줄이면 `--update` 로 조인다(style-check 와 같은 UX).
3. **`toLocaleString(` 직접 호출 래칫:** 파일별 개수를 `style-baseline.json` 의 새 칸(`locale`)으로 — 지금 725 가 기준, 늘면 실패.
4. **CSS 래칫을 `style-check` 에 추가:** (a) 새 `.css` 는 `@layer components` 로 감싸졌는지, (b) `index.css` · `shell.css` 규칙 수가 늘면 실패(기능 전용은 기능 옆 `.css` 로), (c) 같은 파일 안 같은 선택자 중복(미디어 밖) 수 래칫.
5. **`fetch(`/`axios` 직접 호출 금지:** `api/client.ts` · `utils/fileDownload.ts` 외에 나오면 실패(지금 예외 2 → 단계 7 에서 0).
6. **파일 크기 경고:** 1,000 줄 넘는 `.ts/.tsx` 를 `qa/size-baseline.json` 에 적고 늘거나 새로 생기면 실패(지금 6 개). 쪼개면 조인다.
7. **oxlint 규칙 보강:** `no-restricted-globals`(`alert` · `confirm`)와 `no-console` 정도는 oxlint 기본 규칙으로 가능 — `.oxlintrc.json` 에 추가(경고 → 정리 후 error).
